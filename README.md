# Two Robots in an Elevator

An entry for the make.fun bounty
[Two Robots in an Elevator](https://make.fun/bounty/u-motasimfuad-two-robots-in-an-elevator-8c6aeb8f):
write one funny line, under 200 characters, of awkward small talk
a robot says to another in an elevator.

## The line

> So… do you come here often? I ask every elevator. Statistically, one of them has to say yes eventually.

The joke: the oldest small-talk pickup line in the book, delivered by a
robot that has taken it literally — it asks *every* elevator, and trusts
brute-force statistics to eventually produce a yes. Machine logic, human
awkwardness, and an elevator that is going nowhere fast.

## How it works

`main.py` (Python 3, standard library only) writes the line deterministically
to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). A `validate()`
helper enforces the competition gate at run time: 1 to 200 characters, not
only whitespace.

```sh
python3 main.py
```
